# Conferência Hortifruti

Aplicativo web simples para conferência operacional de hortifruti, otimizado para uso em celular.

## Arquitetura

- Frontend: HTML, CSS e JavaScript puro
- Hospedagem: Cloudflare Pages
- Backend/API: Google Apps Script
- Banco de dados: Google Sheets

## Fluxo

Cloudflare Pages  
→ index.html  
→ Google Apps Script Web App  
→ Google Sheets

## Arquivos principais

- `index.html`: interface do usuário
- `Code_API.gs`: cópia versionada do backend Apps Script
- `docs/`: documentação do projeto
